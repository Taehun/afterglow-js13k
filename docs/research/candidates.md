## A. ARCLIGHT (무지개 아치 그리기 플랫포머)

- **한 줄**: 손가락/마우스로 무지개 아치를 그려 발판·다리·무기로 쓰는 아케이드 플랫포머. Rainbow Islands(1987)의 "무지개=구조물" 문법의 현대적 재발굴.
- **코어 루프**: 유니콘 망아지들이 스테이지에 흩어져 있다 → 드래그로 포물선 무지개를 그려(잉크=빛 게이지) 길을 만들고 위험을 덮는다 → 망아지가 자동으로 걸어온다(레밍스식) → 전원 무지개 다리(비프뢰스트)로 탈출시키면 클리어.
- **테마 3층**: 서사(폭풍우로 흩어진 무지개 목장의 망아지 구출) + 아트(그린 아치가 화면에 누적되는 무지개 풍경) + 메카닉(무지개 그 자체가 유일한 도구).
- **입력**: 드래그 한 가지 = 터치 네이티브. 모바일 완벽 대응.
- **오디오**: 아치를 그릴 때 색 구간마다 글리산도(하프 아르페지오), 색상별 음계 매핑.
- **차별화**: 러너/사냥 클리셰 회피. Rainbow Islands는 40년 전 게임이라 재발굴로 인식될 것.
- **리스크**: 포물선 그리기의 판정/물리 튜닝, 레밍스식 AI의 스코프. 잉크 게이지 밸런싱.
- **17일 플랜**: 3일 프로토(드래그 아치+걷는 망아지) / 7일 레벨 15개+기믹 3종 / 4일 폴리시+음악 / 3일 압축·제출.

## B. PRISM SHIFT (파장 전환 퍼즐 플랫포머)

- **한 줄**: 유니콘 뿔이 프리즘 — 세계의 "파장"을 ROYGBIV 7색으로 튜닝하면 그 색의 오브젝트만 실체화되는 퍼즐 플랫포머.
- **코어 루프**: 레벨은 7색 레이어의 중첩 → 좌우 스와이프/QE로 파장 전환 → 빨간 다리는 빨강에서만 밟을 수 있고, 초록 가시는 초록에서만 위험 → 전환 타이밍 퍼즐로 진행. 최후반: 가시광 밖(UV) 히든 레이어.
- **테마 3층**: 서사(무지개가 부서져 7색이 흩어진 세계를 복원) + 아트(단색 세계가 색을 되찾는 진행) + 메카닉(스펙트럼 자체가 규칙).
- **오디오**: 색=조성. 파장을 바꾸면 배경 음악의 키/악기가 바뀐다(7색↔7음계) — Audio 채점 항목과 직결.
- **차별화**: Hue(메인스트림)와 유사하나 js13k 기출 아님. "색 복원"은 반쯤 기출(Chroma Incident)이라 프레이밍 주의.
- **리스크**: 색각 이상 접근성(색+패턴 병기 필수), 레벨 디자인 시간, Hue 유사성 지적 가능.
- **17일 플랜**: 2일 프로토(레이어 전환) / 8일 레벨 20개 / 4일 폴리시+적응형 음악 / 3일 압축·제출.

## C. RAINBOW WAKE (궤적이 트랙이 되는 대시 액션 + 고스트)

- **한 줄**: 유니콘이 달린 자리에 무지개 궤적이 남아 "탈 수 있는 트랙"이 된다 — 이전 런의 나(고스트)가 남긴 무지개를 밟고 더 높이, 더 멀리.
- **코어 루프**: 60초 런 → 대시/점프하며 하늘에 무지개 트랙을 그린다 → 런 종료 후 그 트랙이 지형으로 굳는다 → 다음 런은 이전 런들의 무지개 위에서 시작 → N번의 런을 누적해 도달 불가능해 보이던 별에 닿기. 2019 우승작 xx142-b2.exe의 "과거 시도와의 협동" 공식의 밝은 버전.
- **테마 3층**: 서사(별을 향해 무지개를 쌓는 유니콘) + 아트(런마다 화면이 무지개로 덮여감 — 스크린샷 자생력) + 메카닉(무지개=자기 궤적=지형).
- **Online 얇은 레이어**: relay로 같은 방 플레이어의 라이브 고스트+궤적 표시(혼자여도 완결, 있으면 남의 무지개도 밟음) — 연구에서 검증된 최저비용 패턴.
- **리스크**: Remvst(디펜딩 챔피언)가 물리+유니콘으로 진행 중 — 유사 영역 가능성. 궤적 지형화의 물리 판정. 누적 지형의 성능(파티클/세그먼트 관리).
- **17일 플랜**: 3일 프로토(대시+궤적 굳히기) / 6일 스테이지 5개+업그레이드 / 3일 Online 고스트 / 3일 폴리시 / 2일 압축·제출.

## D. PRISM CONDUCTOR (빛 분해 디펜스 = 음악 작곡)

- **한 줄**: 백색광 스트림에 프리즘을 배치해 7색 빔으로 분해 — 색마다 다른 효과로 잿빛 구름 몬스터를 막는데, **빔 배치가 곧 배경 음악을 작곡**한다.
- **코어 루프**: 웨이브 디펜스. 광원에서 백색광 → 프리즘/거울/렌즈 배치(드래그) → 빨강=화력, 파랑=감속, 노랑=자원… → 각 빔이 비트 위에서 음을 연주(색↔음계) → 좋은 배치는 강할 뿐 아니라 듣기 좋다.
- **테마 3층**: 서사(먹구름에서 무지개를 지키는 유니콘 등대지기 — 뿔=프리즘) + 아트(가산 블렌딩 빔) + 메카닉(무지개 분해가 시스템).
- **오디오**: 게임 시스템 = 음악 생성기. Audio 항목에서 구조적 우위.
- **차별화**: 라이트빔 퍼즐(Chromatron류)은 반기출이지만 "배치=작곡" 결합은 신선. Innovation 상위 노림수.
- **리스크**: TD 밸런싱은 17일에 무겁다. "듣기 좋은 음악이 저절로 나오게" 하는 음악 시스템 설계 난도. 조작이 데스크톱 편향될 위험.
- **17일 플랜**: 3일 프로토(빔+음) / 7일 웨이브·타워 6종·맵 5개 / 4일 폴리시 / 3일 압축·제출.

## E. PURE OF HEART (비폭력 테이밍 어드벤처)

- **한 줄**: 유니콘은 순수한 자에게만 다가온다 — 무기 없이, 오염된 숲의 성난 짐승들을 진정시키고 샘을 정화하는 역(逆)스텔스 어드벤처.
- **코어 루프**: 톱다운 탐험 → 성난 짐승 앞에서 "느리게 움직이기/시선 피하기/선물 놓기" 3동작으로 신뢰 게이지를 채움 → 진정된 짐승이 능력을 빌려줌(멧돼지=덤불 파괴 등) → 뿔 조각으로 오염된 샘 정화 → 구역의 색과 음악이 돌아옴 → 최종적으로 마지막 유니콘이 스스로 다가오는 엔딩.
- **테마 3층**: 서사(중세 동물지 전승 그대로 — 리서치 기반) + 아트(정화 진행 = 채도 복원) + 메카닉(비폭력 접근 = 사냥 해석의 정반대 포지셔닝, fabiosantoscode의 SotC 사냥 게임과 정면 대비).
- **차별화**: "유니콘 사냥" 다크 해석의 안티테제. Witchcat(2025 3위, 젤다라이크+기믹)의 검증된 틀.
- **리스크**: 색 복원 아트는 반기출. 어드벤처는 콘텐츠 양이 필요(맵/NPC/이벤트) — 17일 스코프 압박. "juice"를 만들기 어려운 저속 게임플레이.
- **17일 플랜**: 3일 프로토(신뢰 게이지 스텔스) / 8일 맵 4구역+짐승 4종 / 3일 폴리시 / 3일 압축·제출.

## F. ONE IN 8192 (확률 조작 로그라이트)

- **한 줄**: 유니콘은 1/8192 확률로만 나타난다 — 매 런에서 "행운 변조기"를 쌓아 그 확률을 스스로 끌어올려 전설을 강제로 소환하는 확률 조작 로그라이트.
- **코어 루프**: 짧은 런(2~3분)에서 무지개 조각 수집 → 조각으로 확률 부스터 구매(네잎클로버, 무지개 정렬, 유성우…) → 확률 UI가 실시간으로 1/8192 → 1/512 → 1/13으로 줄어드는 쾌감 → 소환된 유니콘의 축복으로 다음 런 강화 → 13번의 유니콘을 모으면 엔딩.
- **테마 3층**: 서사(전설은 확률 너머에 있다) + 아트(럭 스택마다 화면이 무지개빛으로 물듦) + 메카닉(희소성 그 자체의 게임화 — 개발자 청중에 직관적).
- **차별화**: "유니콘 스타트업 클리커"류 풍자와 달리 액션 런 기반. 가챠 구조를 플레이어가 지배하는 역전 구도.
- **리스크**: 코어 런 액션이 평범하면 "메타만 있는 게임"이 됨. 확률 시스템의 밸런싱. 서바이버류 혼잡 지대와 인접.
- **17일 플랜**: 3일 프로토(런+확률 UI) / 7일 부스터 20종+런 변주 / 4일 폴리시 / 3일 압축·제출.
